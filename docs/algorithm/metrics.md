# Initial route-quality metrics

## Elevation estimates

Elevation is optional metadata from Valhalla's digital terrain dataset, fetched only for shortlisted street routes. For a complete sampled profile, ascent is `sum(max(0, next_height - height))` and descent is `sum(max(0, height - next_height))`, in metres. These are unsmoothed terrain estimates at roughly 30 m spacing (capped at 1024 samples); noise and sampling density can change totals and small climbs may be missed. Missing heights stay null: partial coverage displays chart gaps and no full-route totals. A fully missing profile is unavailable, while genuine zero-metre elevations remain valid. Elevation does not alter the shape-ranking score. Tests cover known climb/descent totals, negative/zero heights, gaps, malformed data, and alternative selection.

The route insight panel marks an approximate steep section only when at least two consecutive sampled intervals each reach an absolute grade of 8% or more, with the combined interval spanning at least 60 m. Grade is `(end_height - start_height) / horizontal_distance * 100`; climbs are positive and descents negative. A missing height, flat interval, or sign change ends a section, so the detector never bridges unknown terrain. This threshold limits isolated spikes, but terrain noise can still affect the result; steep sections are guidance rather than a road-surface or safety assessment.

## Route matching

These are configurable engineering targets, not demonstrated performance. Only router-validated, contiguous network geometry can be eligible for export. Quality scores cannot override access or continuity failures.

All comparisons use a suitable local metric projection; API coordinates use WGS84 `[longitude, latitude]`. Fix drawing fixtures, OSM extract checksum, engine/configuration, and seed in algorithm tests.

The current estimated shape score resamples each metric line at 64 equally spaced arc-length positions. It computes (1) the mean nearest-sample distance in both directions, (2) the ordered discrete Frechet distance, and (3) the average distance from target vertices with turns of at least 25 degrees to the nearest route sample. Each value is normalized by the target bounding-box diagonal. The combined error is `0.55 * symmetric_mean_error + 0.30 * ordered_frechet_error + 0.15 * corner_error`; the displayed score is `clamp(1 - combined_error, 0, 1)`. A score of 1 means the sampled paths coincide. A displayed 98% is not a claim that 98% of the route follows the sketch; read it with the metre-based gap measurements.

The API also reports the average, 95th-percentile, and maximum nearest-sample gap in metres across 64 samples from each line. The map marks the largest sampled gap with a connector between the closest target and route samples. These measurements describe geometry, not road safety or legality. They are still estimates: sampling can miss small features, and the maximum can be sensitive to isolated endpoints or connectors.

For a fixed requested distance, candidate drawing sizes are tested at the target and at the selected ±range (half-range points are included when enabled). The default range is 10%, selectable from exact through ±20%. Ranked candidates use `similarity_score - 0.25 * relative_length_error - 0.15 * retracing_ratio`; `relative_length_error = abs(routed_m - requested_m) / requested_m`, and `retracing_ratio = estimated_repeated_m / routed_m`. An optional hard maximum distance difference rejects candidates outside that limit. Best-shape mode omits a distance target, compares the configured drawing sizes, and removes the length-error term. The coefficients are initial preferences, not user-calibrated weights. Retracing is estimated from repeated visits to 6 m metric grid cells because Valhalla does not expose graph-edge identity; it is a heuristic, not an exact repeated-road measurement.

Pinned mode routes from the selected point, snapped to a routeable street within 250 m; loops return to that street location. An optional placement radius moves the drawing candidates while preserving the pinned start. Area-only mode searches without a required start and rejects any candidate whose routed coordinates leave the selected circle. Both radius modes sample up to 16 deterministic placements with at most four initial drawing waypoints, reroute the top candidates with full waypoint detail, and add up to four more waypoints at the largest separated local deviation peaks. Peak threshold is `max(15 m, 1% of target diagonal)` and minimum spacing is `max(100 m, 8% of target length)`.

Area search reports discrete completed-candidate counts. Workspace requests sample up to 48 placements and allow up to 512 router calls and 60 seconds; up to eight leading candidates receive detailed waypoint refinement. On budget exhaustion, the best available route is returned with a warning; if no candidate succeeded, the API returns a typed failure. Results include up to three alternatives. Similar routes are deduplicated only when their geometry is at least 92% similar and their lengths differ by at most 3%, allowing useful shorter and longer options to remain visible.

`npm run bench:generation:compare` probes one supported Lyon or Andorra graph and records heart, letter, and circle outcomes for walking, running, and cycling in two neighborhoods. It emits elapsed time, measured distance, estimated fit, average/p95/maximum gap, retracing, and alternatives. The benchmark has not been run against the current local graph in this environment. Calibrate thresholds only after collecting fixed-extract results; do not treat the current coefficients as validated user preferences.
