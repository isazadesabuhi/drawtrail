# Initial route-quality metrics

These are configurable engineering targets, not demonstrated performance. Only router-validated, contiguous network geometry can be eligible for export. Quality scores cannot override access or continuity failures.

All comparisons use a suitable local metric projection; API coordinates use WGS84 `[longitude, latitude]`. Fix drawing fixtures, OSM extract checksum, engine/configuration, and seed in algorithm tests.

| Metric          | Formula and units                                                                                                                                                                                                   | Initial target                           | Test                                                                                                 |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| Shape deviation | Resample both paths at uniform arc length. Symmetric mean nearest-point distance: `(mean d(target, route) + mean d(route, target))/2`, meters. Report normalized error divided by target bounding-box diagonal too. | normalized error <= 0.10                 | Identical paths score 0; a translated or deformed fixture scores worse.                              |
| Continuity      | Maximum geodesic gap between the end/start of consecutive routed segments, meters.                                                                                                                                  | <= 2 m; no unsourced straight connectors | Fixed adjacent and disconnected segment fixtures pass/fail independently of shape score.             |
| Access proxy    | Count of segments without successful routing provenance for the selected costing.                                                                                                                                   | 0                                        | Reject missing provenance, wrong mode, and engine failures. This does not establish physical safety. |
| Length error    | `abs(routed_m - requested_m) / requested_m * 100`, percent. Requested length must be positive.                                                                                                                      | <= 20%                                   | Known fixture distances and invalid zero requests.                                                   |
| Repeats         | `repeated_traversal_m / total_routed_m * 100`, percent, using directed/undirected network edge identity where available.                                                                                            | <= 25%                                   | Out-and-back and single-loop fixtures; document fallback when edge IDs are absent.                   |
| Runtime         | Monotonic elapsed wall time from worker start to terminal result, seconds; also report router calls.                                                                                                                | <= 30 s / candidate initially            | Fixed stub delays plus an opt-in fixed-extract benchmark.                                            |

Loop completion also requires the routed end to connect to its start within the continuity tolerance. Display raw measurements before introducing an aggregate ranking. Threshold changes need fixture evidence and a recorded task/ADR revision.
